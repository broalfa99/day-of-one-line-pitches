# A Day of One-Line Pitches

One sentence, 182 characters, that would convince a friend who has never
coded to let an AI agent build their first app idea on
[make.fun](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3):

> If you can explain your idea to a friend, you can build it — just say it
> in one sentence and an AI agent turns it into a real app you can tap
> tonight, no code and nothing to install.

python3 main.py   # writes the pitch to /output/entry.txt
